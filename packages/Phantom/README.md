# Description

Phantom is a uv package that construct toy example where perform tractometry. The examples are built to show that FA based-tractometry is less discriminant than MCM based-tractometry.

See the example_pipeline.ipynb note book for an example.

The first trivial example is called Toy+-. And show off an example where FA-tractometry can't make the difference between a crossing and reduction of FA. 

The second is based on the Disco dataset. It simulates different type of injuries and compare healthy with ill images. The use of the Disco dataset was provided with the courtesy of Emmanuel Caruyer.
