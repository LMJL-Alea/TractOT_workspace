# Description

Phantom is uv package that construct toy example where perform tractometry. The examples are built to show that FA based-tractometry is less discriminant than MCM based-tractometry.

The first trivial example is called Toy+-. And show off an example where FA-tractometry can't make the difference between a crossing and reduction of FA. 

The second is based on the [Disco](https://www.sciencedirect.com/science/article/pii/S2352340921007113) dataset. It simulates different type of injuries and compare healthy with ill images.
